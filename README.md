# Techfest — Ideate Landing Page

A polished, responsive concept landing page inspired by science, engineering, innovation, and student creativity. Built with HTML, CSS, and vanilla JavaScript; no 3D assets or frameworks required.

## Files
- `index.html` — page structure and content
- `style.css` — visual design, responsive layout, CSS illustrations and animations
- `script.js` — scroll progress, reveal animations and mobile navigation

## Run locally
Open `index.html` in a modern browser. Internet is only needed to load the optional Google Fonts; fallback fonts are included.

## Publish to GitHub Pages
1. Create a **public** repository (e.g. `techfest-ideate-landing-page`).
2. Upload the three files and this README to the repository root.
3. Go to **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/(root)`, then Save.
5. Wait for GitHub Pages to publish the website.

## Before submission
Record a short screen demo showing the page from the top through its sections and responsive/mobile layout. Upload the video to Google Drive and set **General access → Anyone with the link → Viewer**. Submit both your GitHub repository link and the Drive demo link as requested by the task.

This is an unofficial concept design, not the official Techfest website. Verify official event details and registration links on the official site before adding them.
